# Text Adventure Game (Java)

A console-based text adventure game built using object-oriented programming.

The game includes:
- Room-based navigation
- Inventory management
- Command parsing
- Item interactions


## Running the Game

Run `Main.java` to start the game.

## Known Issue

If the player dies and restarts in the same session, some item interactions may not reset correctly. Typing "quit" and rerunning the program resolve this.
